Check the fingerprint

Filenames lie. Content doesn't — that goes for the installer too. Every copy of this file produces the same SHA-256 value, so if yours matches, it arrived exactly as it was built.

SHA-256 · DuplicateFinderPro_Setup_v1.5.exe

6CE95D6E0CF58EE02E351B8463C59BCCBE848D5E2B039B30836D7EBF154CB1CB

Open PowerShell in the folder you downloaded to, and run:

Get-FileHash .\DuplicateFinderPro_Setup_v1.5.exe -Algorithm SHA256

The Hash it prints should match the value above, character for character. If it doesn't, don't run the installer — download it again, and if it still differs, email support@almaze.tools.

What Windows will say

DuplicateFinder Pro is built by one person and isn't code-signed yet, so Windows treats the publisher as unknown. Here is exactly what you'll see, in order, and what each step means.

  1. Your browser warns the file isn't commonly downloaded New installers have no download history behind them. Choose Keep — in Edge it sits under the arrow beside Delete.
  2. SmartScreen shows a blue "Windows protected your PC" screen Click More info, then Run anyway. This is what the fingerprint above is for — verify first, then proceed.
  3. The installer asks for administrator permission It installs to Program Files and registers an uninstaller. Nothing outside its own folder is touched.
  4. Open the app and activate Help → Activate, then paste the licence key from your receipt. You need to be online once. After that it works offline forever.
